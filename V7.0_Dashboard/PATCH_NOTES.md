# V7.0: Omni compares up to 3 people
- Omni: up to 3 people, each with a Polar H10 and an O2 ring; your V6 devices become Person 1
- Devices nearby: give each device to a person (or a new one), move it between people; per-device Disconnect / Connect / Forget
- Compare: everyone's latest values in a table, shared heart-rate / SpO2 / HRV charts with a line (colour + style) per person
- A card per person with their tiles, ECG sweep, R-R and motion
- Each H10 gets its own radio; O2 rings and scanning stay off the H10s' radios when they can
- Recordings stay per device, with a _person.json saying whose session it was
